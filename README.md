# Pomodoro Timer

A beautiful, minimalist Pomodoro timer web application with intention setting to help you stay focused and productive. Adding some stuff. 

## Features

- ⏱️ **Pomodoro Technique**: 25-minute work sessions followed by 5-minute breaks
- 🎯 **Intention Setting**: Set a focus goal before starting your timer
- 🎨 **Modern UI**: Clean, glassmorphic design with a calming green gradient
- 🔊 **Sound Notifications**: Audio alerts when work/break sessions complete
- ⌨️ **Keyboard Shortcuts**: Press Enter in the intention field to start the timer
- 📱 **Responsive Design**: Works beautifully on desktop and mobile devices

## How to Use

1. **Set Your Intention**: Type what you want to focus on in the text field below the timer
2. **Start the Timer**: Click "Start" or press Enter after typing your intention
3. **Stay Focused**: Your intention will appear at the top of the screen to keep you on track
4. **Take Breaks**: The timer automatically switches between work (25 min) and break (5 min) sessions
5. **Control**: Use Pause to temporarily stop, or Reset to start over

## Getting Started

Simply open `index.html` in your web browser. No installation or dependencies required!

```bash
# Open in your default browser
open index.html

# Or drag and drop the file into your browser
```

## Features in Detail

### Intention Setting
- Enter your focus goal before starting
- Your intention appears at the top of the screen when the timer is running
- Helps maintain focus on your objective throughout the session

### Timer Controls
- **Start**: Begin your Pomodoro session
- **Pause**: Temporarily pause the timer (intention remains visible)
- **Reset**: Reset to a fresh 25-minute work session

### Automatic Session Switching
- After 25 minutes of work, automatically switches to a 5-minute break
- After the break, returns to work mode
- Sound notification plays at each transition
